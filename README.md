# ROOTS — שורשים

Public browser build of ROOTS, version 3.5.

Play: https://robinshmueli.github.io/roots-survival-play/

Choose a saved world or create a named world with a size and difficulty. Progress saves in the same browser.

Controls: WASD to move, Shift to sprint, mouse to aim, click or Space to use the held item or eat, E to collect and interact, C for the bag, F to craft, R to rotate a building preview, M for the map. The fullscreen button preserves the camera zoom.

Build a cabin with walls, doors, floors and roofs. Roofs fade while inside. Cherry trees drop 2–4 cherries, each restoring 5 hunger, with an eating animation.
